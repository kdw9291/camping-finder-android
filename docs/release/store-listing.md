# Play Console 제출 자료

Play Console 폼에 그대로 복사해 넣을 문구 모음. 글자 수 제한은 항목마다 표기했다.

---

## 1. 앱 세부정보

### 앱 이름 (30자)

```
캠핑각
```

`3자` — 검색 노출을 노려 "캠핑각 - 전국 캠핑장 검색" 같은 형태로 늘릴 수 있으나 하지 않았다.
Play 는 앱 이름의 키워드 채우기(keyword stuffing)를 정책 위반으로 본다. 런처에 표시되는
`app_name` 과 스토어 이름을 일치시키는 편이 사용자 혼란도 적다.

**"캠핑장 찾기" 에서 바꿨다.** 앞 이름은 무엇을 하는 앱인지 즉시 말해 주지만
검색 결과에서 일반명사와 섞여 묻히고 기억에 남지 않는다. `캠핑각` 은 런처 아이콘 아래에
줄바꿈 없이 들어가고("캠핑장 찾기" 는 잘리거나 두 줄이 된다),
**아이콘의 삼각형 텐트와 '각' 이 그대로 맞물린다.**
무엇을 하는 앱인지는 바로 아래 한 줄 설명이 대신 말한다.

> ⚠️ `applicationId` 는 바꾸지 않았다 — `org.duckdns.woodysside.campingfinder`.
> 표시 이름과 패키지명은 별개이고, **표시 이름은 업데이트로 언제든 바꿀 수 있지만
> 패키지명은 업로드 후 영원히 변경 불가**다. 이름이 마음에 안 들면 나중에 고칠 수 있다.

### 간단한 설명 (80자)

```
전국 캠핑장을 조건으로. 전기·온수·반려동물 등 원하는 조건을 모두 갖춘 곳만 골라 봅니다.
```

`45자` — 검색 결과 목록에서 아이콘 옆에 붙는 한 줄이다.
앱 이름(`캠핑각`)이 무엇을 하는 앱인지 말하지 않으므로, 여기서 "무엇"과 "어떻게"를 말한다.

> ⚠️ **건수를 쓰지 않는다.** 원본 공공데이터가 매일 갱신돼 캠핑장 수가 계속 바뀐다.
> 스토어 문구에 박아 두면 어긋나는 순간부터 거짓말이 되고, 고치려면 등록정보를 다시 제출해야 한다.
> 지킬 수 없는 숫자를 약속하지 않는 것이, 이 앱이 "정보 없음" 을 감추지 않는 것과 같은 원칙이다.

### 자세한 설명 (4000자)

```
전국 캠핑장을 조건으로 걸러 찾는 앱입니다.

■ 원하는 조건을 모두 갖춘 곳만

전기, 온수, 무선인터넷, 장작판매, 마트… 필요한 시설을 여러 개 고르면
그것을 '모두' 갖춘 캠핑장만 남습니다. 하나라도 빠지면 나오지 않습니다.
글램핑·카라반·오토캠핑 같은 업종과 반려동물 동반 여부도 함께 걸 수 있습니다.

■ "정보 없음"을 숨기지 않습니다

공공데이터에는 부대시설 정보가 아예 없는 캠핑장이 네 곳 중 한 곳꼴로 있습니다.
많은 앱이 이런 곳을 조용히 빼버립니다. 그러면 '전기 있는 곳'을 검색했을 때
수백 곳이 사라지는데, 그곳들은 전기가 없는 게 아니라 정보가 없는 곳입니다.

이 앱은 그 차이를 구분해 보여줍니다.
빈칸을 '시설 없음'으로 바꿔 말하지 않고, 모른다는 사실을 그대로 알려드립니다.
정보가 확인된 곳만 보고 싶다면 필터에서 끄실 수 있습니다.

■ 지도에서 바로

지도를 움직여 '이 지역에서 검색'을 누르면 화면에 보이는 범위의 캠핑장을 찾습니다.
확대·축소 수준에 따라 검색 반경이 함께 조정됩니다.

■ 이런 분께

· 전기 없는 곳에 갔다가 낭패를 본 적 있는 분
· 반려동물과 함께 갈 곳을 찾는 분
· 조건을 하나하나 확인하며 캠핑장 목록을 뒤지기 지친 분

■ 데이터 출처

한국관광공사가 공공데이터포털에 제공하는 고캠핑 정보를 매일 1회 동기화합니다.
캠핑장 운영 상황은 실제와 다를 수 있으니 방문 전 해당 캠핑장에 확인해 주세요.

■ 개인정보

회원가입이 없습니다. 로그인이 없습니다. 광고가 없습니다.
위치 권한을 요구하지 않으며, 어떤 개인정보도 수집하지 않습니다.
```

`약 800자` — 상단 3~4줄만 접힘 없이 보인다. 그래서 가장 중요한 차별점(조건 조합, 정보 없음 구분)을
앞에 두었다. `■` 는 Play 설명에서 서식이 지원되지 않아 쓰는 관행적 구분자다.

### 왜 `28.7%` 와 `849곳` 을 쓰지 않았나

둘 다 M0 에서 3,082건 전수 조사로 나온 **실측값**이다. 근거가 없는 숫자가 아니다.
그런데도 문구에서는 뺐다 — 원본 공공데이터가 매일 갱신되므로 **어긋나는 것이 시간 문제**이고,
스토어 문구는 어긋났다고 바로 고칠 수 있는 자리가 아니다(등록정보 재제출).

대신 어긋나지 않는 표현으로 바꿨다.

| 실측 | 문구 | 이유 |
|---|---|---|
| 28.7% | **네 곳 중 한 곳** | 25% 라 실제보다 **적게** 말한다. 비율이 오르내려도 참인 쪽으로 틀린다 |
| 849곳 | **수백 곳** | 세 자리 수가 유지되는 한 참이다 |

**일부러 작게 말한 것이다.** 과장이 어긋나면 거짓말이 되지만, 축소가 어긋나면 그냥 겸손한 말이 된다.
정확한 수치는 [M0 데이터 실측](../../../camping-finder-api/docs/process/M0-데이터-실측.md)에 있고,
앱 안에서는 사용자가 필터를 켜고 끄며 그 차이를 직접 본다 — 거기서는 실제 숫자가 그대로 나온다.

## 2. 그래픽 자산

| 항목 | 규격 | 파일 | 필수 |
|---|---|---|---|
| 앱 아이콘 | 512×512 PNG, 알파 없음 | `assets/play-icon-512.png` | 필수 |
| 그래픽 이미지 | 1024×500 PNG/JPG | `assets/play-feature-1024x500.png` | 필수 |

그래픽 이미지에는 **앱 이름이 픽셀로 박혀 있다.** 이름을 바꾸면 이 파일도 함께 바꿔야 한다.
그래서 생성 스크립트를 저장소에 남겼다 — 처음엔 없어서 원본 PNG 를 보고 역설계해야 했다.

```powershell
.\docs\release\make-feature-graphic.ps1 `
    -OutPath .\docs\release\assets\play-feature-1024x500.png `
    -Title '캠핑각' -Subtitle '전국 캠핑장을 조건으로 찾는다'
```

색과 텐트 도형은 런처 아이콘 리소스(`ic_launcher_background.xml`·`ic_launcher_foreground.xml`)에서
그대로 가져온다. 아이콘을 고치면 그래픽도 같이 고쳐진다.

> ⚠️ ImageMagick 을 쓰지 않는다. PATH 의 `convert` 는 ImageMagick 이 아니라
> **윈도우 내장 디스크 변환 도구**(`C:\WINDOWS\system32\convert.exe`)다. 이미지 인자를 주고 실행하면 안 된다.
> `.NET System.Drawing` 으로 직접 그린다.
>
> ⚠️ 이 `.ps1` 은 **UTF-8 BOM 이 있어야 한다.** 없으면 PowerShell 5.1 이 ANSI 로 읽어
> 한글 리터럴이 깨지고 파서 오류가 난다. 실제로 당했다.
| 휴대전화 스크린샷 | 최소 2장, 16:9~9:16, 짧은 변 ≥ 320px | **직접 촬영 필요** | 필수 |
| 태블릿 스크린샷 | — | 없음 | 선택 |

### 스크린샷 촬영 목록 (권장 4장)

실기기에서 `릴리스 빌드`로 찍는다. 디버그 빌드는 로깅 오버레이나 다른 데이터가 섞일 수 있다.

1. **목록** — 검색어 없이 첫 화면. 전체 목록이 보이는 상태
2. **필터 시트** — 부대시설 여러 개가 켜져 있고 "시설 정보가 없는 곳도 포함" 스위치가 보이는 상태 ★
3. **지도** — 마커가 여럿 찍힌 상태, "이 지역에서 검색" 버튼이 보이게
4. **상세** — "정보가 없는 항목" 섹션이 화면에 들어오도록 스크롤한 상태 ★

★ 표시한 두 장이 이 앱을 다른 캠핑 앱과 구분 짓는 장면이다. 반드시 넣는다.

```powershell
# 실기기 화면 캡처
adb shell screencap -p /sdcard/shot.png
adb pull /sdcard/shot.png .\docs\release\assets\screenshot-1.png
```

## 3. 데이터 보안 (Data safety) 양식

Play Console → 정책 → 앱 콘텐츠 → 데이터 보안. **거짓 신고는 앱 게시 중단 사유다.**
현재 코드 기준(위치 권한 없음, 분석 SDK 없음, 광고 없음)의 정답은 아래와 같다.

| 질문 | 답 | 근거 |
|---|---|---|
| 이 앱이 사용자 데이터를 수집하거나 공유합니까? | **아니요** | 서버로 보내는 것은 검색 조건뿐이고 사용자와 결부되지 않는다 |
| 전송 중 데이터가 암호화됩니까? | **예** | 전 구간 HTTPS. release 빌드는 평문 HTTP 를 허용하지 않는다 |
| 사용자가 데이터 삭제를 요청할 수 있습니까? | **해당 없음** | 보관하는 데이터가 없다 |
| 개인정보처리방침 URL | `https://kdw9291.github.io/camping-finder-io/privacy-policy.html` | 필수 (§4) |

> ⚠️ **M5 에서 위치 기능을 붙이면 이 표가 바뀐다.**
> 위치 권한을 추가하는 순간 "위치 → 대략적인 위치" 수집을 신고해야 하고,
> 수집 목적(앱 기능)·필수 여부·기기 내 처리 여부를 다시 답해야 한다.
> 방침 페이지(§4)도 함께 고쳐야 한다. 둘 중 하나만 고치면 불일치로 반려된다.

### 광고 ID

Play Console 은 `AD_ID` 권한 사용 여부를 묻는다. **"아니요"** — 광고 SDK 가 없다.
`com.google.android.gms.permission.AD_ID` 를 선언한 라이브러리가 병합되지 않았는지
병합된 매니페스트로 확인할 것:

```powershell
.\gradlew.bat :app:processReleaseMainManifest
# app\build\intermediates\merged_manifest\release\AndroidManifest.xml 에서 AD_ID 검색
```

## 4. 개인정보처리방침 URL

위치 권한이 없어도 **URL 은 필수**다. (2022년부터 모든 앱에 요구된다.)

**배포 완료 (2026-08-11).** Play Console 의 개인정보처리방침 URL 칸에 이 값을 넣는다.

```
https://kdw9291.github.io/camping-finder-io/privacy-policy.html
```

| | |
|---|---|
| 저장소 | [kdw9291/camping-finder-io](https://github.com/kdw9291/camping-finder-io) (public) |
| Pages | `main` / `(root)` · HTTPS 자동 |
| 원본 | `docs/release/privacy-policy.html` ← **여기를 고치고 저 저장소로 복사한다** |

> ⚠️ **`camping-finder-io` 를 지우거나 private 으로 바꾸면 앱이 내려간다.**
> 무료 플랜에서 private 저장소는 Pages 가 동작하지 않는다.
>
> ⚠️ 방침은 이제 **두 곳에 있다.** 앱 저장소의 원본과 게시본이 어긋나면
> 나중에 어느 쪽이 맞는지 알 수 없다. 고칠 때는 반드시 원본 → 게시본 순서로 간다.

배포 방법(재현용) — GitHub Pages 가 가장 간단하다. 무료이고 HTTPS 가 자동으로 붙는다.

```powershell
# 1. 공개 저장소를 하나 만든다
# 2. privacy-policy.html 을 루트에 넣고 push
# 3. Settings → Pages → Source: Deploy from a branch / main / (root)
```

> 저장소 이름을 `<아이디>.github.io` 로 하면 URL 이 짧아지고(`/privacy-policy.html`)
> **푸시만으로 Pages 가 켜진다.** 프로젝트 저장소는 3번을 손으로 해야 하고 경로에 저장소명이 붙는다.

> ⚠️ 이 URL 은 **앱이 게시된 동안 계속 살아 있어야 한다.**
> 링크가 죽으면 정책 위반으로 앱이 내려간다. 그래서 앱 API 서버(`woodys-side.duckdns.org`)에
> 얹지 않았다 — EC2 를 폐기·재생성할 수 있게 만든 무상태 설계와, 절대 죽으면 안 되는 페이지는
> 같은 곳에 두지 않는 것이 맞다.

## 6. 비공개 테스트 — 테스터 모집

**개인 개발자 계정은 비공개 테스트 12명 × 14일 연속을 통과해야 프로덕션에 올릴 수 있다.**
이것이 일정의 임계 경로다. 코드가 끝난 뒤에 모으기 시작하면 2주가 통째로 늘어난다.

조건을 정확히 알아둘 것:

- **12명이 "옵트인"** 해야 한다. 설치까지가 아니라 테스트 참여 링크를 눌러 참가한 상태
- **14일 연속** — 중간에 인원이 12명 아래로 떨어지면 카운트가 끊긴다. 여유 있게 15~18명을 모은다
- 테스터는 **Google 계정 이메일**로 등록한다. 카카오 계정이 아니다

### 모집 문구 (카톡·커뮤니티 붙여넣기용)

```
캠핑장 찾는 앱을 만들었는데, 스토어에 올리려면 테스터 12명이 2주간 필요합니다.
설치해두기만 하면 되고, 따로 하실 일은 없습니다. 광고·회원가입·결제 전부 없습니다.

참여해주실 분은 Google 계정 이메일(gmail 주소)만 알려주세요.
등록해드리면 링크를 보내드립니다. 2주 뒤에 지우셔도 됩니다.

- 전국 캠핑장을 전기·온수·반려동물 같은 조건으로 걸러 찾는 앱입니다
- 한국관광공사 공공데이터 기반이고, 개인정보는 아무것도 수집하지 않습니다
```
